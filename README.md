# ResearchPilot

AI-powered research assistant for academic literature review generation.

## Tech Stack

- React
- Node.js
- Express
- PostgreSQL
- Docker

## Branching Strategy

This project follows the **GitHub Flow** branching model.

- `main` contains the stable version of the project.
- Each new feature is developed in a separate feature branch.
- Feature branches are merged into `main` after completion and testing.

Current feature branches:
- feature/readme
- feature/frontend
- feature/backend
- feature/docker
